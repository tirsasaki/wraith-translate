Overview

Wraith Translate translates any text you select on a web page, or the whole page at once. Select text, click the small button that appears next to it, and the translation shows in a tooltip. To translate a page, click the toolbar icon and press Translate this page. The source language is detected automatically; the target language is set in Settings.

Four providers are supported: 9router (an OpenAI-compatible AI gateway), Custom (any OpenAI-compatible service), Claude from Anthropic, and DeepL. Only the selected provider is used; settings for the others stay saved.

Usage

  1. In Settings, choose a provider, enter its connection details, and click Save settings.
  2. Click Test translation to verify the connection.
  3. On any web page, select some text and click the small button that appears.
  4. Read the result in the tooltip. The full translation is always shown, with no inner scrolling. Click Copy to copy it; press Esc or click elsewhere to close it.
  5. To see the same text in another language, use the Translate to menu at the bottom of the tooltip. This applies only to that tooltip and does not change your saved target language.

Very long translations make the tooltip taller, so scroll the page itself to read the rest. Each translation is limited to 5,000 characters. The button does not appear on browser-internal pages (chrome://), the Chrome Web Store, or the built-in PDF viewer.

Translate a full page

  1. Open the page, then click the Wraith Translate toolbar icon and press Translate this page. You can also choose Translate this page with Wraith Translate from the right-click menu, or press Alt+W (change the shortcut at chrome://extensions/shortcuts).
  2. The toolbar popup also lets you change the target language, switch selected-text and full-page translation on or off, and open this settings page.
  3. A small bar appears at the bottom of the page. It shows progress, lets you pick another language, switch between Original and Translation, and close to restore the page.
  4. Open the popup and press Show original page (or use the × on the bar) to restore the original page.

With Replace text, each piece of text is swapped in place and the page layout is kept. With Show both, the translation is added under each paragraph, so you can read the original next to it. Code blocks, form fields, and elements marked translate="no" or class="notranslate" are left alone.

With Translate as you scroll on, only text near the screen is sent to your provider; the rest is translated as you reach it. New content that loads while you scroll (infinite scroll) is picked up after you stop scrolling. Identical strings on a page are translated once. Pages translated through an LLM provider use tokens, so long pages cost more; DeepL counts characters.

9router

  1. Make sure 9router is running and at least one AI provider is connected in its dashboard.
  2. Enter the Base URL, for example http://localhost:20128/v1, or your server address if 9router runs elsewhere.
  3. Enter the API key from the 9router dashboard (leave empty if auth is off).
  4. Click Connect. Wraith Translate calls GET {baseUrl}/models and fills the Model list with every model available in your 9router, grouped by the prefix before /.
  5. Pick a model and click Save settings.

If you add or remove AI connections in 9router, click Connect again to refresh the list. Translations are sent to POST {baseUrl}/chat/completions with an Authorization: Bearer … header. For any address other than localhost or 127.0.0.1, the browser asks for access to it when you click Connect or Save.

Claude

  1. Create an API key in the Anthropic Console and paste it into API key.
  2. Click Load models. The list comes from GET https://api.anthropic.com/v1/models, so it always matches what your account can use.
  3. Pick a model and click Save settings.

Translations go to POST /v1/messages with the x-api-key and anthropic-version headers. Usage is billed at your API account's rates. Smaller models are usually faster and cheaper for short translations.

DeepL

  1. Create a DeepL API account (Free and Pro plans exist) and copy your authentication key.
  2. Paste it into API key. Keys ending in :fx use api-free.deepl.com; all others use api.deepl.com.
  3. Click Save settings.

DeepL is a dedicated translation engine rather than a language model, so there is no model choice. The detected source language is shown in the tooltip. When the quota runs out, the tooltip shows a quota message (error 456).

Privacy and security

  • Text you select is sent only to the provider you chose, and only after you click the translate button. Page text is sent only after you start a page translation.
  • API keys are stored in chrome.storage.local on this device and are not synced to your Google account. Keys never enter the web page: all API calls are made by the service worker.
  • Translations are rendered as plain text, not HTML, so they cannot inject scripts.
  • The selection is treated as text to translate, not as instructions, to reduce prompt-injection risk from web pages. Do not translate confidential text through a provider you do not trust.

Install

Chrome, Edge, Brave, Opera, Vivaldi, Arc (use the Chromium package):

  1. Extract the zip into a folder.
  2. Open chrome://extensions (or edge://extensions, brave://extensions, opera://extensions, vivaldi://extensions) and turn on Developer mode.
  3. Click Load unpacked and select the extracted folder.
  4. After changing code, click the reload icon on the extension card, then reload the tab you are testing.

Firefox (use the Firefox package, Firefox 140 or newer):

  1. Open about:debugging#/runtime/this-firefox and click Load Temporary Add-on, then pick manifest.json from the extracted folder (or the zip). Temporary add-ons are removed when Firefox closes.
  2. For a permanent install, sign the package at addons.mozilla.org (unlisted is fine), or use Firefox Developer Edition / Nightly with xpinstall.signatures.required set to false.
  3. Open this settings page and click Allow access when the banner appears, so the selection button works on all sites.
